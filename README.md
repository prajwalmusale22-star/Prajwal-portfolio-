# Prajwal Musale | Portfolio

Personal portfolio built with plain HTML, CSS and JavaScript. No build step.

Features: animated neural-network background, typing headline, Aurora and Coral themes, live GitHub repositories, scroll progress bar, 3D project cards, mobile friendly. Press `/` to jump to contact.

## Deploy on GitHub Pages
1. Create a repository (name it `prajwalmusale22-star.github.io` for a root URL).
2. Upload everything in this folder, keeping `index.html` at the top level.
3. Go to Settings > Pages > Deploy from a branch > main / root.
4. Your site goes live at `https://prajwalmusale22-star.github.io`.

## Edit
- Text and projects: `index.html`
- Styling: `css/style.css`
- Behaviour: `js/main.js`
- Photo: replace `assets/profile.jpg`
